# Product Backlog — Aplicativo Ritmo

Priorização em três níveis: **Alta**, **Média** e **Baixa**. Cada item traz a user story correspondente e o(s) requisito(s) de origem (RF/RNF).

---

## Prioridade alta

| ID | User Story | Prioridade | Requisito |
|----|-------------|------------|-----------|
| US01 | Como usuário, quero criar hábitos com nome, descrição, frequência, duração, horário e dias da semana, para organizar minha rotina pessoal. | Alta | RF01 |
| US02 | Como usuário, quero criar eventos e cronogramas (provas, reuniões, compromissos) integrados à linha do tempo dos meus hábitos, para centralizar minha agenda em um só lugar. | Alta | RF02 |
| US03 | Como usuário, quero marcar diariamente meus hábitos e eventos como concluídos, parcialmente concluídos ou não concluídos, para acompanhar meu cumprimento no dia a dia. | Alta | RF03 |
| US04 | Como usuário, quero visualizar minha taxa de consistência e um gráfico de sequência de dias para cada hábito, para entender meu desempenho ao longo do tempo. | Alta | RF04 |
| US05 | Como usuário, quero visualizar uma grade semanal com meus hábitos agendados, para ter uma visão clara da distribuição da minha rotina. | Alta | RF12 |
| US06 | Como desenvolvedor, quero que o aplicativo seja construído em React Native e Node.js, compilado exclusivamente para Android, para garantir a base tecnológica definida para o produto. | Alta | RNF01 |
| US07 | Como usuário, quero que meus hábitos sejam armazenados em um banco de dados local com índices, para que o aplicativo responda rapidamente às minhas consultas. | Alta | RNF05 |
